# 08 — Разбор импорта Sticky Notes

Статус: импорт готов, разбора нет · Зависит от: 03, 04 · Оценка: 3 дня

## Зачем

product.txt §20. Импорт уже переносит заметки (открытые — «как на экране», остальные — в архив),
но классификация слабая: у пользователя 383 из 433 стали просто «Заметкой»; спецификация просит
категории Ideas / Prompts / Links / Personal / Work / Credentials / Old / Duplicates и быстрый
просмотр. Сейчас пользователь видит только счётчики.

## Поведение

1. После импорта (и из «Библиотека → Настройки → Импорт») доступен **«Разобрать импорт»**.
2. Экран разбора — группы с количеством и примерами (по 3 метки/первые строки):
   - Похоже на пароли/доступы (→ Private, будут зашифрованы — 03)
   - Ссылки · Промпты · Идеи · Справка (команды, хосты, пути)
   - Давно не менялись (> 1 года)
   - Дубликаты и почти-дубликаты (≥ 90 % общих слов)
   - Остальное
3. Для группы одним действием: «Принять тип», «Всё в архив», «Всё в корзину», «Посмотреть» (список
   как в библиотеке, с переключателем типа у каждой строки).
4. Почти-дубликаты: пара показывается рядом, «Оставить обе / Оставить новую / Объединить».
5. Разбор можно бросить на середине; прогресс хранится.

## Классификация (локально, без AI)

Улучшения к `sticky::classify`, каждое с тестом на синтетических примерах:
- Prompt: длинный текст (> 300 символов) с обращением к модели («ты —», «you are», «act as»,
  «твоя задача», «ответь», «формат ответа») или маркерами `{{ }}`, `###`, `Role:`.
- Link: ≥ 50 % текста — URL(ы).
- Reference: ≥ 2 строк похожи на команды (`$ `, `git `, `docker `, `ssh `, `C:\`, `/usr/`),
  хосты (`*.internal`, IP:port), ключи `KEY=value`.
- Idea: «идея», «а что если», «попробовать», «можно сделать», вопросительная первая строка.
- Personal/Work: без AI не определяем; группа «Остальное». С AI (10) — по согласию.
- Почти-дубликаты: MinHash по словам (64 хеша), порог Jaccard 0,9; 500 заметок — < 50 мс.

## Данные

```sql
ALTER TABLE imported ADD COLUMN suggested_kind TEXT;
ALTER TABLE imported ADD COLUMN group_key TEXT;      -- secrets | links | prompts | ideas | reference | old | duplicate | other
ALTER TABLE imported ADD COLUMN reviewed INTEGER NOT NULL DEFAULT 0;
```

## Критерии приёмки

- [ ] На синтетическом наборе из 100 размеченных заметок точность по группам ≥ 80 %
      (набор — фикстура в `tests/`, без реальных данных).
- [ ] Групповое действие применяется одной транзакцией и отменяется «Отменить».
- [ ] Private из группы паролей после «Принять» зашифрованы (проверка байтов БД).
- [ ] Экран разбора открывается ≤ 150 мс на 500 импортированных заметках.

## Не делаем

Отправку заметок во внешний AI без отдельного явного согласия (§20, §22).
