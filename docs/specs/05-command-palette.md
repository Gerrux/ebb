# 05 — Command Palette

Статус: первый набор готов (2026-10-04) · Зависит от: бар поиска (готов)

Сделано: палитра живёт в баре поиска — запрос, начинающийся с `>`, показывает команды вместо
заметок. Входы: `>` в поиске, хоткей «Команды» (`hotkey.palette`, по умолчанию Win+Alt+K, запасной
Ctrl+Alt+K, настраивается как остальные), Ctrl+K при фокусе на слое. Реестр, нечёткий поиск
(целая строка > начало > начало слова > подстрока > подпоследовательность; синонимы, ё = е) и
последние пять (`palette.recent`) — чистый модуль `src/commands.rs`; выполнение — `Outbox::Command`
→ `app/palette.rs::run_command`, который зовёт те же функции, что и остальной интерфейс. 23 команды:
новая заметка, поиск, показать идеи / промпты / цели / напоминания / ссылки, обзор, архив,
корзина, настройки, показать/скрыть слой, слой под окнами, свернуть/развернуть, слой на монитор N,
затемнение N (проценты), фон: следующий, импорт, автозапуск, резервная копия, выход; для выбранной
карточки на видимом слое — в архив, закрепить/открепить. Число вне диапазона не выполняется.
Автозапуск и копия идут в фоне, итог — тостом на слое.
Не сделано: «Показать забытые», раскладки и Zen (нет самих функций), смена типа карточки (нужен
выбор типа), трей и хоткеи через те же команды и единая очередь (11, A2), подсказка хоткея в строке
команды. Известное: хоткей поиска при открытой палитре закрывает бар, а не переключает на заметки;
итог фоновой команды не виден, пока слой скрыт, и заменяет тост с «Отменить»; «монитор N» молчит,
если монитор отключили между показом списка и Enter.

## Зачем

product.txt §19. Сейчас команды разбросаны: трей, хоткеи, F1/F2/F3, кнопки в библиотеке.
Палитра даёт один вход с клавиатуры.

## Поведение

1. Открывается в том же баре, что захват и поиск (третий режим), чтобы не создавать окно:
   - глобально — хоткей палитры (кандидаты `Win+Alt+K`, `Ctrl+Alt+K`; §19 предлагает Ctrl+K,
     но глобальный Ctrl+K занят браузерами/IDE);
   - внутри поиска — ввод `>` в начале строки переключает в команды (как в VS Code);
   - когда фокус на слое — `Ctrl+K`.
2. Нечёткий поиск по названиям и синонимам (`архив` находит «Показать архив»), последние 5
   использованных команд сверху.
3. Команды (первый набор):
   - Новая заметка · Поиск · Показать идеи / промпты / цели / напоминания (открывают поиск с фильтром)
   - Показать забытые (01) · Weekly Review (02) · Архив · Корзина · Настройки
   - Показать/скрыть слой · Слой под окнами вкл/выкл · Переместить слой на монитор N
   - Прозрачность / затемнение: `затемнение 40` (параметр числом)
   - Раскладка: свободная / секции / стопка / Zen (06)
   - Импорт из Sticky Notes · Запускать при входе вкл/выкл
   - Для выбранной карточки на слое: В архив · Закрепить · Изменить тип
4. Enter — выполнить; команды с параметром показывают подсказку формата.

## Реализация

- `Mode::Command` в `bar.rs`; реестр команд `commands.rs`:
  `struct Command { id, title, synonyms, when: fn(&Ctx) -> bool, run: fn(&mut App, Arg) }`.
  Выполнение — через `Outbox` в корневой viewport (как сейчас действия поиска).
- Трей и хоткеи вызывают те же команды по `id` — одна точка правды.
- Нечёткий поиск: подпоследовательность + бонус за начало слова, без зависимостей.

## Критерии приёмки

- [ ] Каждая команда из меню трея и F-клавиш доступна в палитре.
- [ ] `>архив` в поиске открывает архив в библиотеке.
- [x] Открытие палитры ≤ 30 мс (тот же бар), фильтрация ≤ 1 мс. (Фильтрация: 0,02 мс на отладочной
      сборке; открытие — тот же путь, что у поиска, отдельно не замерялось.)
- [x] Команды, неприменимые сейчас (нет выбранной карточки), скрыты.
