# 07 — Настройки, хоткеи, внешний вид, данные

Статус: частично (вкладка «Настройки» в библиотеке) · Зависит от: — · Оценка: 3 дня

## Зачем

Из отзыва: «Как попасть в настройки?» — сделано минимально. Остались: свои сочетания клавиш
(на этой машине Win+Alt+F занят, и пользователь это видит только как «Ctrl+Alt+F»), тёмное меню
трея, резервная копия, поведение Private.

## Поведение

### Горячие клавиши
- Для каждого действия (Записать, Найти, Палитра, Библиотека, Показать/скрыть слой, Zen) — поле
  «Нажмите сочетание». Проверка: `RegisterHotKey` сразу; занято → «Занято другой программой»
  и предложение свободных вариантов.
- Сброс к умолчанию. Сочетание можно отключить.

### Внешний вид
- Тема акцента: системная / своя. Затемнение, фон (есть). Размер шрифта карточек (S/M/L).
- **Тёмное меню трея**: следовать теме Windows. Реализация — `SetPreferredAppMode` (uxtheme,
  ordinal 135) + `AllowDarkModeForWindow` (133) + `FlushMenuThemes` (136) через `raw-dylib` по
  ординалам, с проверкой версии сборки Windows (≥ 17763) и тихим отказом при ошибке. Это
  недокументированный API (так делают Explorer, Notepad++, PowerToys) — изолировать в `win.rs`.
- Анимации: вкл/выкл (уважать системную настройку «Эффекты анимации»,
  `SPI_GETCLIENTAREAANIMATION`).

### Поведение
- Секции слоя и лимиты (01), период Rediscover, cooldown, день Weekly Review (02).
- Private: время показа, очистка буфера, скрытие от записи экрана (03).
- Показ слоя из трея: сразу / с анимацией.

### Данные
- «Сделать резервную копию» → `VACUUM INTO '<путь>'` (консистентная копия без остановки),
  плюс зашифрованный экспорт секретов под паролем (03, опционально).
- «Восстановить из копии» (с подтверждением, текущая база → в `ebb.db.bak`).
- Экспорт в Markdown/JSON (все карточки, кроме секретов; секреты — только с паролем).
- Автоматическая копия раз в неделю в `%LOCALAPPDATA%\Ebb\backups`, храним 4 последние.

## Данные

`settings(key, value)` — ключи с префиксами: `hotkey.capture`, `hotkey.search`, …, `ui.font`,
`ui.animations`, `backup.auto`, `private.reveal_seconds`. Значения хоткеев — `"Win+Alt+N"`,
разбор в `shell.rs` (сейчас кандидаты зашиты в код).

## Реализация

- Регистрация хоткеев переезжает из констант в `shell::apply_hotkeys(&[(Action, Combo)])`;
  перерегистрация — сообщением в окно shell (хоткеи принадлежат его потоку).
- Захват сочетания в UI: egui получает клавиши, но Win-модификатор перехватывает система —
  на время записи ставить `WH_KEYBOARD_LL` хук в потоке shell и снимать сразу после.

## Критерии приёмки

- [ ] Смена хоткея применяется без перезапуска и переживает перезапуск.
- [ ] Занятое сочетание не сохраняется, пользователь видит почему.
- [ ] Меню трея тёмное при тёмной теме Windows; при сбое API — светлое, без падения.
- [ ] Резервная копия открывается как обычная база (тест: `VACUUM INTO`, открыть, сравнить counts).
- [ ] Отключённые системой анимации отключают анимации Ebb.
