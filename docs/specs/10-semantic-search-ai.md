# 10 — Семантический поиск и AI-помощник (опционально)

Статус: не начато (после MVP) · Зависит от: 03 (исключение Private), 01, 08 · Оценка: 1–2 недели

## Зачем

product.txt §7 (semantic similarity), §15 (кластеры), §21 (AI как вспомогательный слой), §22
(privacy). Лексический поиск FTS5 уже быстрый, но не находит «что я писал про ценообразование» по
заметке «annual pricing plan».

## Принципы

- Выключено по умолчанию. Включение — отдельный экран с объяснением, что и где обрабатывается.
- **Локально по умолчанию**: эмбеддинги считаются на машине. Облачная модель — только отдельной
  опцией, с явным согласием и списком того, что отправляется.
- Private и Secure Reference **никогда** не участвуют: ни в эмбеддингах, ни в запросах к моделям.
- Ничего не делается молча: предложения (теги, кластеры, дубликаты) показываются как подсказки,
  применяются только по нажатию.

## Этап A — локальные эмбеддинги (семантический поиск)

- Модель: небольшая мультиязычная sentence-embedding модель (≈ 100–150 МБ, RU+EN), ONNX,
  инференс на CPU. Кандидаты сравнить на ruMTEB-подобном наборе из своих фикстур:
  `multilingual-e5-small`, `paraphrase-multilingual-MiniLM-L12-v2`.
- Модель скачивается по кнопке (не в дистрибутиве), путь и хеш проверяются.
- Индекс: вектора в SQLite (`card_vectors(card_id, dim, vec BLOB, model, updated_at)`), поиск —
  brute-force cosine в Rust (10 000 × 384 dim ≈ 4 мс, SIMD не нужен на этом масштабе).
- Гибридный ранжир: `score = 0.6 * bm25_norm + 0.4 * cosine`, если оба есть; семантика только
  добавляет результаты, которых нет в FTS.
- Индексация в фоне с `THREAD_MODE_BACKGROUND_BEGIN`, по 32 карточки, пауза при активности
  пользователя (последний ввод < 2 с → ждать).
- Процесс: инференс в **отдельном процессе-воркере** (`ebb.exe --embedder`), который
  запускается на время индексации и выходит. Иначе рантайм ONNX (+100–200 МБ) навсегда осядет в
  памяти слоя, что ломает бюджет README.

## Этап B — кластеры и дубликаты (§15)

- Кластеры: агломеративная кластеризация по косинусу (порог 0,8), показывать кластеры ≥ 5 карточек:
  «14 заметок про Pricing» → Создать коллекцию (тег) · Объединить дубликаты · Оставить.
- Дубликаты: косинус ≥ 0,95 — предложение в Weekly Review (02).

## Этап C — вопросы по заметкам (§21)

- «Что я писал про onboarding?» в палитре/поиске → поиск (гибридный) + ответ-сводка с ссылками на
  карточки. Генерация: только облачная модель по согласию **или** локальная LLM (отдельный
  большой скачиваемый компонент). В промпт идут только найденные не-Private карточки,
  список показывается пользователю до отправки.

## Критерии приёмки

- [ ] С выключенной опцией нет модели на диске, нет процессов-воркеров, нет сетевых запросов.
- [ ] Private-карточки отсутствуют в `card_vectors` (тест).
- [ ] Память слоя в простое не меняется после индексации (воркер завершён).
- [ ] На фикстуре из 200 заметок с 30 размеченными запросами гибридный поиск находит нужную
      карточку в топ-5 в ≥ 85 % случаев против текущего FTS (зафиксировать базовую цифру).

## Не делаем

Обучение на данных пользователя, телеметрию, автоматическое применение предложений AI.
