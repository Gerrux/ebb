# 06 — Раскладки слоя и несколько мониторов

Статус: частично (один слой, свободный холст) · Зависит от: 01 (секции) · Оценка: 4–5 дней

## Зачем

product.txt §16, §17, MVP 13. Сейчас слой — один, на выбранном мониторе, раскладка только
свободная. Пользователь с двумя мониторами держит заметки на обоих (21 открытая: 14 на втором,
7 на основном); при импорте заметки с основного монитора пришлось переносить на второй.

## Поведение

### Раскладки (§16)
| Раскладка | Описание |
|---|---|
| Свободный холст | как сейчас; зона Rediscover справа (01) |
| Секции | колонки Закреплено / Сегодня / Вспомнить; порядок внутри — перетаскиванием |
| Стопка | одна колонка по центру, самые важные сверху, остальные свёрнуты до строки |
| Zen (§17) | 3–5 карточек крупно: текущий фокус (Pinned/Goal), одна идея, одно напоминание, одна из Rediscover; всё остальное скрыто |

- Переключение: палитра (05), трей, настройки. Позиции в свободном холсте сохраняются при
  переключении туда и обратно.
- Zen включается и хоткеем (опционально), выходит по Esc.

### Мониторы
1. Слоёв может быть несколько: по одному на монитор, включается галочкой для каждого монитора
   в настройках. По умолчанию — один, на втором мониторе (как сейчас).
2. Карточка принадлежит монитору (`monitor` в модели §23). Перетаскивание карточки за край слоя
   на соседний монитор переносит её (если там включён слой).
3. Отключили монитор → его карточки временно показываются на оставшемся слое в отдельной зоне
   «С монитора 2» и возвращаются, когда монитор снова подключён (по device id, как в импорте).
4. Смена разрешения/масштаба: позиции хранятся в долях рабочей области + абсолютный размер в
   логических точках; карточки, вышедшие за край, прижимаются внутрь.
5. Импорт Sticky Notes: заметки с монитора, на котором есть слой, ставятся на свои места
   на этом слое (сейчас — только монитор основного слоя).

## Данные

```sql
ALTER TABLE cards ADD COLUMN monitor TEXT;          -- device interface path (win::Monitor::device_ids[0]); NULL = основной слой
ALTER TABLE cards ADD COLUMN layout_pos TEXT;       -- JSON: позиции для раскладок «секции»/«стопка» (порядок)
-- settings: layers = JSON [{device, layout, backdrop, tint}], zen_hotkey
```

## Реализация

- Каждый дополнительный слой — deferred viewport с правилами `LAYER | FADE`, создаётся при включении.
  Память: каждый слой ≈ +10–15 МБ private (замерить); по умолчанию один.
- События мониторов: `WM_DISPLAYCHANGE` и `WM_DEVICECHANGE` в окне shell → пересчёт `win::monitors()`.
- DPI: хранить логические точки; при переносе между мониторами с разным масштабом пересчитывать
  через `GetDpiForMonitor` (сейчас импорт делит на масштаб слоя — ошибка при разных DPI, см. 11).
- `app.rs` разделить: `layer.rs` (один слой, его карточки и раскладка) и `app.rs` (оркестрация).

## Производительность

- Второй слой не должен влиять на первый кадр: создаётся после первого кадра основного.
- Простой: CPU 0 для любого числа слоёв (каждый рисует только по событию).

## Критерии приёмки

- [ ] Отключение монитора (симуляция: сменить `layers` на несуществующий device) не теряет карточки.
- [ ] Перетаскивание карточки на соседний монитор сохраняет её после перезапуска там.
- [ ] Zen показывает ≤ 5 карточек и восстанавливает раскладку по Esc.
- [ ] Бенч: память в простое с двумя слоями — зафиксировать и указать в настройках рядом с галочкой.

## Не делаем

Виртуальные рабочие столы Windows (привязка слоя к рабочему столу) — позже, если попросят.
