# 09 — Контекстный resurfacing

Статус: не начато (после MVP) · Зависит от: 01 · Оценка: 4 дня

## Зачем

product.txt §9: при запуске Figma — дизайн-заметки, в VS Code — сниппеты, в ChatGPT — промпты,
в понедельник — цели недели, в пятницу — давно не пересмотренные идеи.

## Поведение

1. Когда пользователь переключается в приложение, для которого есть связанные карточки, в зоне
   Rediscover слоя (01) тихо появляются до 3 карточек с причиной «Для Figma».
   Никаких всплывающих окон поверх работы.
2. Связь «приложение ↔ карточки» появляется без настройки:
   - по тегам и словам: процесс `Figma.exe` ↔ `#figma`, «figma», «дизайн», «макет»;
   - по истории: карточки, которые пользователь открывал/копировал, пока это приложение было
     активным (≥ 2 раза) — связь запоминается.
   Пользователь может убрать связь («Не показывать для Figma»).
3. Для браузеров контекст — только имя процесса, **без URL и заголовков вкладок** по умолчанию.
   Заголовок окна (например, «ChatGPT — Chrome») — отдельная опция с явным пояснением.
4. Контекст времени: понедельник утро → Goals; пятница после обеда → старые Ideas.
5. Смена контекста не чаще раза в 2 минуты на одно приложение (не дёргать слой при Alt+Tab).
6. Геолокация — не делаем (§9 разрешает только по явному включению; пользы для этого сценария мало).

## Реализация

- Слежение за активным окном без поллинга: `SetWinEventHook(EVENT_SYSTEM_FOREGROUND,
  WINEVENT_OUTOFCONTEXT)` в потоке shell (у него уже есть цикл сообщений). Из события —
  `GetWindowThreadProcessId` → `QueryFullProcessImageNameW` → имя exe.
- Своё окно Ebb и рабочий стол игнорировать.
- Слой под окнами: карточки появляются, даже если слой перекрыт, — пользователь увидит их,
  когда посмотрит на второй монитор (это и есть «ambient»).

## Данные

```sql
CREATE TABLE contexts(app TEXT, card_id INTEGER, weight REAL, source TEXT /*tag|history|manual*/,
                      blocked INTEGER NOT NULL DEFAULT 0, PRIMARY KEY(app, card_id));
CREATE TABLE app_usage(app TEXT PRIMARY KEY, first_seen INTEGER, last_seen INTEGER);
```
Все данные о приложениях — только локально. Кнопка «Забыть историю приложений» в настройках.

## Производительность

- Хук: ≤ 0,1 мс на событие; пересчёт кандидатов для приложения — из кеша, ≤ 2 мс.
- Простой без переключений окон: CPU 0.

## Критерии приёмки

- [ ] Переключение Alt+Tab 20 раз за минуту не вызывает больше одной смены карточек на приложение.
- [ ] Выключенная опция «Заголовки окон» → в базе нет ни одного заголовка окна.
- [ ] «Не показывать для X» работает сразу и после перезапуска.
- [ ] CPU в простое 0 (хук не будит приложение, если нет переключений).

## Не делаем

Анализ содержимого экрана, клавиатурный ввод, URL, геолокацию.
