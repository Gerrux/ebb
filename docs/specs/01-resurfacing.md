# 01 — Resurfacing: Pinned / Today / Rediscover

Статус: core реализован · Зависит от: — · Остаток: Today/Sections, «выбрать дату» в «Позже»

Сейчас: раз в день Rediscover (`settings.rediscover_day`), день начинается в 06:00 по местному времени
(`resurface::DAY_STARTS_AT`). Подбор делается при запуске и, пока Ebb работает, утром по таймеру
(`request_repaint_after` до начала дня, сам подбор — в фоновом потоке со своим соединением), а также
после выхода из сна или смены часов/пояса (`WM_POWERBROADCAST`/`WM_TIMECHANGE` → `Event::ClockChanged`;
уже сделанный за день подбор не повторяется). До 3 карточек из архива, не открывавшихся ≥ 7 дней;
вчерашние без реакции уходят обратно в архив (`ignored_count + 1`), открытые остаются как ручные.
Новые кладутся в свободные слоты (на полном слое — каскадом поверх).

«Позже» на карточке слоя (не закреплённой): Завтра / Через 3 дня / Через неделю / Через месяц —
карточка уходит в архив с `review_at` на утро нужного дня (за час до подбора — запас на переход
на летнее время) и возвращается подбором с причиной «Напоминание на сегодня». `ignored_count` не
растёт (в отличие от snooze в Weekly Review), тост «Вернётся …» с отменой.

## Зачем

product.txt §8, §10, §11, §12, §16. Главный цикл продукта — Capture → Forget → **Resurface** →
Act → Archive. Сейчас слой статичен: всё, что на нём, лежит там всегда; архив (у пользователя
~430 заметок) не возвращается никогда. «Закрепить» ставит булавку, но ни на что не влияет.

## Поведение

Слой состоит из трёх секций (порядок и видимость настраиваются, по умолчанию все):

| Секция | Что | Сколько |
|---|---|---|
| **Pinned** | Закреплённые. Никогда не уходят сами | без лимита (предупреждение при > 12) |
| **Today** | Созданные/изменённые за последние 24 ч, напоминания со сроком сегодня, цели недели по понедельникам | до 5 |
| **Rediscover** | Старые карточки, которые стоит вспомнить | 2–3 |

Итого на слое 5–15 карточек (§1).

1. Карточка в Rediscover подписана причиной: «Ты записал это 73 дня назад», «Напоминание на
   сегодня», «Давно не открывал».
2. Действия на карточке Rediscover (§11): **Оставить** (переносит в «на слое» без секции),
   **Позже** (snooze: 3 дня / неделя / месяц / выбрать дату), **В архив**, **В корзину**,
   **Закрепить**.
3. Смена набора Rediscover — не чаще раза в `rediscover_period` (по умолчанию утром при первой
   активности после 06:00 и после выхода из сна), без мигания в течение дня.
4. Ручное размещение важнее автоматики: если пользователь передвинул карточку, она становится
   «на слое вручную» и не уходит сама.
5. Cooldown (§10): карточка, показанная в Rediscover, не возвращается туда `cooldown_days`
   (по умолчанию 14) — если только это не напоминание со сроком.
6. Information decay (§12): карточка на слое (не Pinned, не ручная), которую не открывали 30 дней
   и которая 3 раза была в Rediscover без реакции, получает пометку «кандидат в архив» и
   предлагается в Weekly Review (02). Сама в архив не уходит.
7. Напоминания: `через 2 недели …` при захвате ставит `review_at`; в этот день карточка
   попадает в Today с причиной «Напоминание».

## UI

- Режим «Секции» — новая раскладка слоя (в дополнение к свободному холсту, см. 06):
  три колонки или три ряда с заголовками «Закреплено / Сегодня / Вспомнить».
- В свободном холсте секции не рисуются: Rediscover-карточки появляются в зарезервированной
  области (правый край) с подписью причины; Pinned и ручные — там, где их положили.
- Появление/уход — существующие анимации карточек (fade + rise).

## Данные

```sql
ALTER TABLE cards ADD COLUMN placement TEXT NOT NULL DEFAULT 'manual';
  -- manual | pinned | today | rediscover | archive (archived=1 остаётся источником правды для архива)
ALTER TABLE cards ADD COLUMN review_at INTEGER;          -- напоминание / snooze до
ALTER TABLE cards ADD COLUMN last_resurfaced_at INTEGER;
ALTER TABLE cards ADD COLUMN resurface_count INTEGER NOT NULL DEFAULT 0;
ALTER TABLE cards ADD COLUMN ignored_count INTEGER NOT NULL DEFAULT 0;  -- показ без взаимодействия
ALTER TABLE cards ADD COLUMN priority INTEGER NOT NULL DEFAULT 0;       -- -1 low, 0, 1 high
CREATE INDEX cards_review ON cards(review_at) WHERE review_at IS NOT NULL;
```

`last_viewed_at` уже пишется при открытии из поиска; добавить: раскрытие/правка/копирование на слое.

## Алгоритм

Score для кандидатов Rediscover (архив и не-закреплённые, не в корзине, не snooze):

```
score = w_forgot * forgotten(days_since_viewed)      // растёт до ~60 дней, потом плато
      + w_type   * type_weight(kind)                 // idea 1.0, goal 0.8, prompt 0.3, reference 0.2, private 0
      + w_prio   * priority
      + w_ctx    * context_match                      // 0 до спеки 09
      + w_sem    * semantic_match                     // 0 до спеки 10
      - w_seen   * recently_resurfaced(cooldown)      // бесконечный штраф внутри cooldown
      - w_ign    * ignored_count
```

Выбор: top-N по score с разнообразием (не два одинаковых типа подряд, не две карточки из одной
«пачки импорта» за день). Детерминированно для одного дня (seed = дата), чтобы перезапуск не
менял набор.

Реализация: модуль `resurface.rs` — чистые функции `candidates(now, cards) -> Vec<Pick>` с
тестами на фиксированном времени; планировщик в `app/mod.rs` пересчитывает при запуске (в фоне,
через 3 с), на рассвете (`request_repaint_after` до ближайшей границы) и при выходе из сна
(`WM_POWERBROADCAST` / `PBT_APMRESUMEAUTOMATIC` в окне shell).

## Производительность

- Пересчёт на 10 000 карточках ≤ 20 мс в фоновом потоке (одна выборка + сортировка в Rust).
- Никаких таймеров чаще раза в минуту; в простое CPU = 0.

## Критерии приёмки

- [ ] Юнит-тесты: cooldown соблюдается; snooze скрывает до даты; напоминание попадает в Today в
      свой день; одинаковый набор при повторном расчёте в тот же день; Private никогда не в Rediscover.
- [ ] Карточка, передвинутая пользователем, не уходит со слоя автоматически.
- [ ] После 30 дней симуляции (тест со сдвигом «now») на слое не больше 15 карточек и ни одна
      не показывалась в Rediscover дважды за 14 дней.
- [ ] Pin влияет: закреплённая не уходит ни при каком расчёте.
- [ ] Бенч без регрессий; CPU в простое 0.

## Не делаем

Push-уведомления, звуки, счётчики «непрочитанного», серии и геймификацию (§27).
