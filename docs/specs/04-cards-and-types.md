# 04 — Карточки и типы: редактирование, теги, быстрые действия

Статус: частично · Зависит от: 01 (snooze, priority) · Оценка: 5–6 дней

## Зачем

product.txt §3, §4, §14, §18. Сейчас тип определяется только при захвате и не меняется, теги
живут внутри текста, из быстрых действий нет Snooze/Edit/More, у типов нет своих полей. Из отзыва:
кнопки на карточках не давали обратной связи (исправлено уведомлением «Отменить»), заголовок из
первой строки мешал (убран).

## Поведение

### Карточка на слое
- Без наведения: только текст, теги-чипы, возраст. Никаких рамок кнопок (§18).
- Наведение: Закрепить · Копировать · Позже (snooze) · В архив · «⋯» (Изменить тип, Приоритет,
  Цвет акцента, В корзину, Свернуть).
- Двойной клик — правка текста. Enter в конце строки — перенос; Ctrl+Enter / клик мимо / Esc —
  сохранить (Esc сохраняет, не отменяет: потерять текст хуже).
- Свернуть: карточка сжимается до одной строки (§3 collapse), разворачивается кликом.
- Правка тегов: чипы кликабельны (удалить ×), «+» открывает поле с автодополнением по
  существующим тегам (частота использования). `#тег` в тексте по-прежнему работает.

### Типы (§4)
| Тип | Своё |
|---|---|
| Note | — |
| Idea | статус Potential / Maybe / Explore / Important (чип, клик меняет) |
| Prompt | название; тело; переменные `{{name}}`; «Копировать» спрашивает значения переменных в мини-форме и копирует подставленный текст |
| Link | домен и заголовок страницы (см. ниже), кнопка «Открыть» |
| Goal | цель (текст), срок, статус (active / done / dropped), период пересмотра (неделя/месяц) |
| Reminder | дата `review_at`, «Сделано» → архив |
| Reference | моноширинный шрифт для строк, похожих на команды/пути/хосты; копирование строки кликом |
| Private / Secure Reference | см. 03 |

- Смена типа сохраняет текст; поля, которых у нового типа нет, не удаляются (хранятся в `meta`).
- Link: заголовок страницы **не** запрашивается из сети автоматически (local-first §22). Кнопка
  «Подтянуть заголовок» делает один GET по нажатию. Favicon — только из того же запроса, кешируется
  в базе (≤ 16 КБ).

## Данные

```sql
ALTER TABLE cards ADD COLUMN meta TEXT NOT NULL DEFAULT '{}';   -- JSON полей типа
ALTER TABLE cards ADD COLUMN collapsed INTEGER NOT NULL DEFAULT 0;
ALTER TABLE cards ADD COLUMN accent TEXT;                         -- переопределение цвета, NULL = по типу
CREATE TABLE tags(name TEXT PRIMARY KEY, uses INTEGER NOT NULL);  -- для автодополнения, пересчёт триггером
```

`meta` пример: `{"idea_status":"explore"}`, `{"goal":{"target":"…","deadline":1790000000,"status":"active","cadence":"week"}}`,
`{"prompt":{"variables":["topic","tone"]}}`, `{"link":{"url":"…","title":"…","favicon":"base64"}}`.

Теги: хранение остаётся в `cards.tags` (csv, индексируется FTS); `tags` — производная таблица.

## Реализация

- `card.rs`: `Kind::Secure`, парсер переменных `{{…}}`, распознавание Reference-строк.
- `app.rs` сейчас ~1150 строк: вынести карточку в `card_ui.rs` (рендер, действия, редактор тегов,
  меню «⋯») до начала работы.
- Меню «⋯»: egui `Popup` внутри слоя (не Win32-меню).
- Link fetch: `std::net` + `rustls`? — новая зависимость ради одной кнопки избыточна; использовать
  WinHTTP (`WinHttpOpen`/`WinHttpSendRequest`) в фоновом потоке, таймаут 5 с, только HTTPS.

## Производительность

- Рендер 50 карточек на слое: кадр ≤ 4 мс (сейчас узкое место — тексты; кешировать galley по
  (id, width, updated_at)).
- Автодополнение тегов ≤ 1 мс (таблица `tags` в памяти после первого открытия).

## Критерии приёмки

- [ ] Все действия наведения доступны с клавиатуры в режиме выбора карточки (Tab по карточкам,
      Enter — правка, Delete — в корзину) и видны egui_mcp по подписям.
- [ ] Смена типа Idea → Goal → Idea не теряет статус идеи.
- [ ] Prompt с `{{topic}}` копирует текст с подставленным значением.
- [ ] Ни одного сетевого запроса без нажатия «Подтянуть заголовок» (проверка: Resource Monitor /
      `netstat -b` во время работы).
- [ ] Свёрнутая карточка остаётся свёрнутой после перезапуска.

## Не делаем

Rich-text/markdown-рендер, вложения и картинки, проекты и подзадачи (§28 «не добавлять»).

## Открытые вопросы

- Цвет карточки как у Sticky Notes (желтый/фиолетовый) — переносить `Theme` из импорта в `accent`?
  Предлагаю: да, приглушённым акцентом на полосе сверху, не заливкой.
